# Geula Gallery

A bilingual (Hebrew / English) online gallery and store where an Israel-based painter shows and sells her original paintings. It includes payment processing (Cardcom, PayPal), Israeli tax documents (Morning), shipping (zone rate table, DHL Express, manual), and the Israeli consumer-law flows.

> **Work in progress.** The first version is being built on the `feat/gallery-v1` branch. See the open pull request.

## Security policy

This repository is **public**. Never commit secrets, API keys, `.env*` files, customer data or business identity details. Credentials live only in local `.env.local` files and in the hosting provider's environment variables.
